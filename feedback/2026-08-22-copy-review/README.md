# Copy review, round of 22 Aug 2026

Reviews of the site copy pack generated by `npm run copy:dump`
(`.claude/copy-review/INDEX.md` plus one file per page).

**How to file a review:** one markdown file per reviewer, named for you,
e.g. `COPY-FEEDBACK-yourname.md`, in this folder. Findings as
`path:line`, current text, proposed replacement. Nobody edits anyone
else's file, and nobody edits the pages directly: Nick applies or
delegates the edits.

## Note on the interactives

Two pages embed diagrams whose copy lives in JavaScript, not the page
HTML. The pack extracts it under "Embedded interactive" with a
`path:line` each, but the extraction is best-effort: short UI labels held
in variables can still slip through. If something looks missing, open the
file before concluding it isn't there.
