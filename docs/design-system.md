# Design system

The website is the reference expression of the Thermal Dawn brand:
`Company Context +/Brand & Style/BRAND.md` is written by reading this site, and
the print registers and customer documents take their tokens from it.

## One stylesheet, in layers

`assets/css/style.css` is a single file that grew in dated blocks. Each block
was appended, not merged, so **source order is load-bearing**: at equal
specificity the later rule wins, and several sections rely on that (the
`body.dark` overrides, the orange-band re-ink, the v8 readability block). Add
new rules in a new labelled block at the end; edit earlier lines only for pure
token substitutions.

The blocks, roughly:

| Block | What it added |
|---|---|
| base and tokens | `:root` colour, type, spacing, radius, shadow and motion tokens |
| components | hero, sections, cards, tiers, tables, forms, FAQ, footer |
| v4 to v7 (Jul to Aug 2026) | the dark-page treatment, the orange band, the proof panel, the ghost-button pattern for dark surfaces, per-surface overrides |
| v8 (6 Sep 2026 design pass) | readability overrides, the measure, hierarchy fixes, rhythm tokens, motion recipe, reduced-motion baseline |

`feedback/2026-09-06-design-pass/DESIGN-PASS.md` records the last full pass:
every contrast ratio before and after, the motion additions, and what was
found and deliberately not touched.

## Tokens that matter

- **Orange.** `--td-orange: #FF9C00` is the brand accent and is **not usable as
  text on light backgrounds** (1.96:1 on cream). On light surfaces use
  `--td-orange-ink: #AD6B00` for display text and `--td-orange-text: #AD5700`
  for body-size text. `#FF9C00` is for rules, fills and text on dark.
  `#AD5700` must never go on dark.
- **Ink on the orange band** is `#1c1514`, not white (7.11:1).
- **Neutrals.** `--td-black #1d1e1c`, `--td-grey #6e6965`, `--td-grey-2
  #B5B3B1`, `--td-line #e2ddd8`, papers `#ffffff / #f6f4f2 / #efeae6`. The site
  also carries some sixty hard-coded greys forming undocumented ramps; a
  consolidation is a known, unscheduled pass.
- **Measure.** `--measure` caps running text at about 75 characters (a `ch`
  in Montserrat is about 1.49 characters wide, so 50ch is the cap). The FAQ is
  one column at that measure by decision: a two-column layout was built and
  dropped in September.
- **Type.** Montserrat throughout, self-hosted as `.woff2` in `assets/fonts/`
  (Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800, Black 900).
  h1 is ExtraBold 800 since the September pass; h2 Black 900; body 16.5px on
  1.62. Each page preloads ExtraBold and Regular only.
- **Motion.** One lift recipe (2px, 150ms) on buttons, cards and post cards;
  a scroll reveal on sections below the fold (14px, 500ms, once); the FAQ
  slide (260ms, Web Animations API with a timer fallback because the finish
  event stalls in a hidden tab); count-up on live stats. All of it switches
  off under `prefers-reduced-motion`. Nothing on the hero starts at
  `opacity:0`; it is the LCP.

## Rules a change must respect

1. **Bump `?v=` on every reference** to `style.css` or any JS file you edit,
   on all 28 pages. `npm run check:cachebust` catches a miss.
2. **Contrast:** 4.5:1 for body text, 3:1 for large, measured against the
   real composited backdrop. The design pass table is the baseline.
3. **Do not add wrappers with `transform`, `filter`, `backdrop-filter`,
   `perspective` or `contain` between `body` and `#site-header`**; the sticky
   header breaks.
4. **Do not animate the width of any iframe ancestor.** See the height
   contract in [pages-and-content.md](pages-and-content.md).
5. **Page-local CSS in an animation must stay inside that file.** Each
   animation self-hosts its fonts and carries a copy of the shared palette
   comment; change the palette in `style.css` and in each animation.

## Relationship to the other design systems

| System | Where | Relationship |
|---|---|---|
| **Brand record** | `Brand & Style/BRAND.md` | Written off this site. Records the 13 Aug 2026 move from `#f4921d` to `#FF9C00`, the contrast rule, the safety-signage exceptions |
| **Print registers** | `Brand & Style/Templates/`, `td-doc.css` | Five A4 registers (Legal, Report, Investor Pack, Technical Product, Product Sheet) on the same tokens |
| **Customer documents** | `Sales +/Consumer/Sales Playbook/_Templates/Design system/`, `td-customer.css` | Proposals and notes, generated by the customer model. Same tokens; DM Mono on data surfaces; dark mode on the **platform's** tokens rather than this site's warm dark, so a plan previews the app |
| **Platform dashboard** | `../TD-Platform/packages/dashboard/src/styles.css` | Shares the orange (`--brand-rgb: 255,156,0`), Montserrat and DM Mono, the brand dot and the horizon line. The homepage animation's scene comes from there |

If the orange ever changes again, it changes in `BRAND.md` first, then here,
then in the platform, then in the three animations.
